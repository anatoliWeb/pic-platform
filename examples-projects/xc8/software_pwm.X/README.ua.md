# software_pwm.X

## Призначення

Початковий приклад software PWM для PIC18F452 з однією PWM-групою, яка працює від таймера.

## Що перевіряє

- Software PWM для довільних GPIO-виходів.
- Один timer source для однієї спільної PWM-групи.
- Різний duty cycle для кожного каналу при одній базовій PWM-частоті.
- Керування яскравістю LED без використання hardware PWM через CCP.

## Компоненти Proteus

- PIC18F452
- кварц 10 MHz і конденсатори навантаження
- 4 LED
- 4 резистори по 330R
- підтягування MCLR на 10 k

## Піни підключення

- RB0: вихід LED0, приблизно 10% duty
- RB1: вихід LED1, приблизно 30% duty
- RB2: вихід LED2, приблизно 60% duty
- RB3: вихід LED3, приблизно 90% duty

## Очікувана поведінка

- Чотири LED світяться з різною яскравістю.
- RB0 є найтьмянішим каналом.
- RB3 є найяскравішим каналом.
- Усі канали мають одну базову PWM-частоту.

## Примітки

- У прикладі використовується одна software PWM group і `Timer2` як джерело tick.
- Приклад навмисно окремий від hardware PWM прикладу `pwm.X`.
- `Timer0`, `Timer1` і `Timer3` поки лишаються запланованими варіантами джерела таймера для майбутньої перевірки.
- Для вихідних ліній використовується `LATB` разом із `TRISB`, а не `PORTB`.

## Статус

Готово до перевірки в Proteus.
