# adc_buttons.X

## Призначення

Приклад кнопок через ADC ladder на одному аналоговому вході PIC18F452.

## Що перевіряє

- Відповідність ADC діапазонів кнопкам.
- Виявлення стабільного стану кнопки.
- Перемикання LED при новій стабільній кнопці.
- Логування сирих значень ADC через UART.

## Компоненти Proteus

- PIC18F452.
- Resistor ladder на AN0.
- Чотири кнопки в ланцюжку.
- Чотири LED на RB0..RB3.
- Virtual Terminal.
- Підтримка Timer1 tick.

## Піни підключення

- RA0 / AN0: вхід ladder.
- RB0..RB3: виходи LED.
- RC6/TX: UART debug-вивід.
- Interrupt Timer1: потрібен для debounce на основі tick.

## Очікувана поведінка

- Стабільний ADC-діапазон відповідає одному логічному ID кнопки.
- Натискання нової кнопки перемикає відповідний LED.
- Утримання тієї самої кнопки не призводить до повторних перемикань.
- Сирі значення ADC друкуються в термінал.

## Примітки

- Приклад використовує налаштовані ADC діапазони, отримані з вимірів у Proteus.
- Якщо змінюється resistor ladder, таблицю потрібно підлаштувати.
- Цей приклад використовує тільки стабільні зміни кнопки; click і hold у ньому не показані.
- Menu logic свідомо не входить до scope фази 1.

## Статус

Перевірено в Proteus.

Ручну перевірку в Proteus успішно виконано.
