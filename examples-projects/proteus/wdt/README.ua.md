# wdt Симуляція Proteus

## Статус
Перевірено в Proteus.

## Firmware

Шлях до XC8 HEX:

`../../hex/xc8/wdt/wdt.hex`

C18 HEX ще не доступний для цього проєкту.

## MPLAB проєкти

- `../../xc8/wdt.X`
- `../../c18/wdt.X`

## Очікувана поведінка

- У нормальному режимі `wdt_clear()` викликається регулярно.
- При симульованому зависанні виклики `wdt_clear()` припиняються.
- MCU виконує reset, і startup-індикація повторюється.

## Нотатки для Proteus

- Не копіюйте HEX у цю папку.
- Перезбирайте MPLAB-проєкт, щоб оновити HEX.
- Proteus має завантажувати HEX із спільної папки `hex/`.
- Оновлюйте `proteus-version.txt` після створення або збереження проєкту Proteus.
