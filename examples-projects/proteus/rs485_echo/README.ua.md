# rs485_echo Proteus simulation

## Статус
Потрібне ручне налаштування Proteus.

## Firmware

XC8 HEX:

`../../hex/xc8/rs485_echo/rs485_echo.hex`

C18 HEX поки недоступний для цього проєкту.

## MPLAB-проєкти

- `../../xc8/rs485_echo.X`
- `../../c18/rs485_echo.X`

## Підключення до PIC18F452

| Сигнал | Ніжка PIC18F452 | Підключення в Proteus |
|---|---:|---|
| UART TX | RC6 / pin 25 | DI RS485-трансивера |
| UART RX | RC7 / pin 26 | RO RS485-трансивера |
| RS485 DE/RE | RB2 / pin 35 | Керування напрямком трансіверу |
| VDD | pins 11, 32 | +5V |
| VSS | pins 12, 31 | GND |
| MCLR | pin 1 | Pull-up reset за потреби |

## Очікуваний результат

Вхідні RS485-байти друкуються в UART і відразу відправляються назад через трансівер.

## Примітки

- Не копіюйте HEX у цю папку.
- Після збірки оновлюйте HEX через MPLAB-проєкт.
- Proteus має завантажувати HEX із спільної папки `hex/`.
- Оновлюйте `proteus-version.txt` після ручного збереження проєкту Proteus.
