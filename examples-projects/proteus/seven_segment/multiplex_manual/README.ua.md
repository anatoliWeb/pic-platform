# Нотатки Proteus: multiplex_manual

## Призначення

Документація-заготовка для перевірки fixed-point форматування десяткових значень при ручному multiplex refresh.

## Проєкт прикладу

- `examples-projects/xc8/seven_segment/multiplex_manual.X`

## Що перевірити

- стабільний manual refresh при яскравості 100%
- правильне позиціювання десяткової крапки для `12.34`, `7.5` і `0.05`
- правильне доповнення нулями для `00.05`
- правильне розташування мінуса для `-12.3`
- heartbeat на RE1 перемикається при зміні сцени
- RE0 лишається в нулі під час нормальної роботи

## Статус

Готово до перевірки в Proteus.
