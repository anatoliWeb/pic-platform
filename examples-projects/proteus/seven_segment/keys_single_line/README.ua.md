# Нотатки Proteus: keys_single_line

## Призначення

Документація-заготовка для перевірки shared-line button input разом із форматованим виводом на дисплей.

## Проєкт прикладу

- `examples-projects/xc8/seven_segment/keys_single_line.X`

## Що перевірити

- UP і DOWN змінюють форматоване чотирирозрядне значення
- поточний активний редагований розряд блимає
- click на OK перемикає режим leading zero
- double-click на OK перемикає вирівнювання left/right
- hold-repeat на OK змінює яскравість без пошкодження refresh

## Статус

Готово до перевірки в Proteus.
