# lcd_hd44780 Симуляція Proteus

## Статус
Проєкт Proteus: очікує ручного створення.

## Firmware

Шлях до XC8 HEX:

`../../hex/xc8/lcd_hd44780/lcd_hd44780.hex`

- `../../hex/c18/lcd_hd44780/lcd_hd44780.hex`

## MPLAB проєкти

- `../../xc8/lcd_hd44780.X`
- `../../c18/lcd_hd44780.X`

## Нотатки для Proteus

Підключіть лінії даних, керування та живлення LCD HD44780.

## Примітки
- Не копіюйте HEX у цю папку.
- Перезбирайте MPLAB проєкт, щоб оновити HEX.
- Proteus має завантажувати HEX із спільної папки `hex/`.
- Оновіть `proteus-version.txt` після створення або збереження проєкту Proteus.
