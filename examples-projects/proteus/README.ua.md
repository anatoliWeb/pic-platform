# Симуляції Proteus

Папки для симуляцій Proteus зберігаються тут.
Кожен приклад має окрему папку з назвою проєкту без `.X`.
HEX-файли зберігаються у спільній папці `examples-projects/hex/` і не дублюються всередині папок Proteus.
Переважним firmware є XC8 HEX, тому що збірки XC8 уже перевірені. C18 HEX можуть існувати лише для проєктів, які пройшли перевірку C18.

## Структура папок

- `examples-projects/proteus/<project>/`
- `README.md` та `README.ua.md` для нотаток із ручного налаштування
- `proteus-version.txt` для версії Proteus і назви збереженого файлу проєкту
- реальні файли `.pdsprj` / `.dsn` можна комітити, якщо їх створено вручну

## Спільні шляхи до firmware

- XC8: `../../hex/xc8/<project>/<project>.hex`
- C18: `../../hex/c18/<project>/<project>.hex`, якщо він доступний

## Правила

- Не копіюйте HEX-файли у папки Proteus.
- Не створюйте фальшиві файли `.pdsprj` або `.dsn`.
- Не комітьте згенеровані backup/cache-файли.
- Оновлюйте `proteus-version.txt` після ручного збереження проєкту Proteus.
- Тримайте нотатки короткими та практичними.
