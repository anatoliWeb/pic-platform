# Експортовані HEX-файли

У цій папці зберігаються HEX-файли, експортовані після успішної збірки XC8- та C18-прикладів.

- Шлях: `examples-projects/hex/xc8/<project>/<project>.hex`
- Шлях: `examples-projects/hex/c18/<project>/<project>.hex`
- Ці файли призначені для Proteus та інших симуляторів PIC18.
- Перегенеровуйте їх після повторної збірки відповідного `.X` проєкту.
- Тут мають зберігатися лише файли після успішної збірки.

У поточному проході оновлено XC8 HEX-файли для `adc`, `adc_buttons`, `adc_read`, `blink`, `button`, `ccp_capture` та `ccp_compare`.
