# LCD HD44780 Driver

## Description

GPIO-based HD44780 LCD driver in 4-bit mode.
Provides initialization, cursor control, and text output.

## API

- `lcd_init_pins()`
- `lcd_init()`
- `lcd_clear()`
- `lcd_set_cursor()`
- `lcd_write_char()`
- `lcd_write_string()`

## Example

```c
lcd_init_pins(&PORTD, &TRISD, &PORTC, &TRISC, 0u, &PORTC, &TRISC, 1u, 4u, 5u, 6u, 7u);
lcd_init();
lcd_set_cursor(0u, 0u);
lcd_write_string("System OK");
```

## Notes

- Works in 4-bit transfer mode.
- Command/data timing relies on delay layer.

## Dependencies

- `core/compiler.h`
- `core/types.h`
- `core/delay.h`
