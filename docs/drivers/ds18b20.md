# DS18B20 Driver

## Description

Temperature sensor driver built on top of OneWire API.
Supports conversion start, scratchpad read, CRC check, and temperature output.

## API

- `ds18b20_start_conversion()`
- `ds18b20_read_scratchpad()`
- `ds18b20_read_temperature_raw()`
- `ds18b20_read_temperature_celsius()`
- `ds18b20_get_temperature_raw()`
- `ds18b20_get_temperature_celsius_x10()`

## Example

```c
int16_t temp_x10;

if (ds18b20_start_conversion(0) != 0u)
{
    if (ds18b20_read_temperature_celsius(0, &temp_x10) != 0u)
    {
        // temp_x10 contains Celsius * 10
    }
}
```

## Notes

- Uses scratchpad data with CRC validation.
- `*_celsius()` returns fixed-point value in x10 scale.

## Dependencies

- `core/compiler.h`
- `core/types.h`
- `drivers/onewire`
