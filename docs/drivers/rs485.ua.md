# RS485 Драйвер

## Опис

RS485 протокольний шар поверх UART.
Надає керування напрямком (DE/RE), побайтовий обмін і обмін кадрами.

## API

- `rs485_set_tx()`
- `rs485_set_rx()`
- `rs485_send_frame()`
- `rs485_receive_frame()`

## Приклад

```c
uint8_t tx_data[3] = {0x10u, 0x20u, 0x30u};
uint8_t rx_data[16];

rs485_init(&PORTB, &TRISB, 2u);
rs485_send_frame(tx_data, 3u);                        // відправити команду
len = rs485_receive_frame(rx_data, sizeof(rx_data)); // прийняти відповідь
```

## Особливості

- Керування TX/RX виконується через DE/RE пін із використанням GPIO.
- Цілісність кадру перевіряється внутрішнім CRC (у поточному API доступний `rs485_crc8`).

## Залежності

- `drivers/uart`
- `drivers/gpio`
