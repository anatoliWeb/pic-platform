# RS485 Driver

## Description

RS485 protocol layer built on top of UART.
Provides direction control (DE/RE), byte transfer, and framed data exchange.

## API

- `rs485_set_tx()`
- `rs485_set_rx()`
- `rs485_send_frame()`
- `rs485_receive_frame()`

## Example

```c
uint8_t tx_data[3] = {0x10u, 0x20u, 0x30u};
uint8_t rx_data[16];

rs485_init(&PORTB, &TRISB, 2u);
rs485_send_frame(tx_data, 3u);                     // send command
len = rs485_receive_frame(rx_data, sizeof(rx_data)); // receive response
```

## Notes

- TX/RX direction is controlled by DE/RE pin via GPIO.
- Frame integrity is validated by internal CRC check (current API exposes `rs485_crc8`).

## Dependencies

- `drivers/uart`
- `drivers/gpio`
- `core/compiler.h`
- `core/types.h`
