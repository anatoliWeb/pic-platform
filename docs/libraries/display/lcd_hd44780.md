# LCD HD44780 Driver

## Description

HD44780 LCD driver with two transports:

- GPIO 4-bit mode (`lcd_*`).
- PCF8574 I2C backpack (`lcd_i2c_*`).

Both provide initialization, cursor control, and text output.

## API

### GPIO transport

- `lcd_init_pins()`
- `lcd_init()`
- `lcd_clear()`
- `lcd_set_cursor()`
- `lcd_write_char()`
- `lcd_write_string()`

### I2C transport

- `lcd_i2c_init(i2c_addr, i2c_clock_hz)` — full init (I2C + LCD + backlight on); ready on success.
- `lcd_i2c_attach(i2c_addr)` — bind to an already-initialized I2C bus. Probe only:
  it never calls `i2c_init()`, never runs the HD44780 init sequence and never
  clears the display. Run `lcd_i2c_controller_init()` afterwards.
- `lcd_i2c_controller_init()` — run only the HD44780 init sequence on the
  address bound by `init()` or `attach()`; returns `LCD_I2C_NOT_INITIALIZED`
  if no address is bound.
- `lcd_i2c_probe(i2c_addr)` — check device presence.
- `lcd_i2c_last_status()` — last operation status.
- `lcd_i2c_is_ready()` — ready flag (cleared on NACK).
- `lcd_i2c_clear()`
- `lcd_i2c_home()`
- `lcd_i2c_set_cursor(row, col)`
- `lcd_i2c_write_char(c)`
- `lcd_i2c_write_string(str)`
- `lcd_i2c_backlight(on)`

Status values: `LCD_I2C_OK`, `LCD_I2C_INVALID_ARGUMENT`,
`LCD_I2C_NOT_INITIALIZED`, `LCD_I2C_NO_ACK`.

The address is a 7-bit I2C address (no masking); address `0x00` and addresses
above `0x7F` are rejected. A NACK short-circuits the current operation (no
further I2C transactions) and clears the ready flag. Display operations
(`clear`, `home`, cursor, text, backlight) refuse to touch the bus with
`LCD_I2C_NOT_INITIALIZED` until the controller is initialized again through
`lcd_i2c_init()` or `lcd_i2c_controller_init()`. The PCF8574 pin mapping is
configurable at compile time through `LCD_I2C_PIN_RS/RW/EN/BL` and
`LCD_I2C_DATA_SHIFT` (defaults match the common backpack: P0=RS, P1=RW,
P2=EN, P3=Backlight, P4..P7=D4..D7); invalid mappings fail the build.

## Example

### GPIO

```c
lcd_init_pins(&PORTD, &TRISD, &PORTC, &TRISC, 0u, &PORTC, &TRISC, 1u, 4u, 5u, 6u, 7u);
lcd_init();
lcd_set_cursor(0u, 0u);
lcd_write_string("System OK");
```

### I2C

```c
if (lcd_i2c_init(0x27u, 100000u) != LCD_I2C_OK) {
    /* backpack missing or miswired */
}
lcd_i2c_set_cursor(0u, 0u);
lcd_i2c_write_string("System OK");
```

## Notes

- GPIO transport works in 4-bit transfer mode.
- I2C transport drives a PCF8574 backpack on the shared I2C master.
- Command/data timing relies on delay layer.
