# LCD HD44780 Driver

## Description

HD44780 LCD driver with two transports:

- GPIO 4-bit mode (`lcd_*`).
- PCF8574 I2C backpack (`lcd_i2c_*`).

Both provide initialization, cursor control, and text output.

## API

### GPIO transport

- `lcd_init_pins()`
- `lcd_init()`
- `lcd_clear()`
- `lcd_set_cursor()`
- `lcd_write_char()`
- `lcd_write_string()`

### I2C transport

- `lcd_i2c_init(i2c_addr, i2c_clock_hz)`
- `lcd_i2c_clear()`
- `lcd_i2c_home()`
- `lcd_i2c_set_cursor()`
- `lcd_i2c_write_char()`
- `lcd_i2c_write_string()`
- `lcd_i2c_backlight(on)`

## Example

### GPIO

```c
lcd_init_pins(&PORTD, &TRISD, &PORTC, &TRISC, 0u, &PORTC, &TRISC, 1u, 4u, 5u, 6u, 7u);
lcd_init();
lcd_set_cursor(0u, 0u);
lcd_write_string("System OK");
```

### I2C

```c
lcd_i2c_init(0x27u, 100000u);
lcd_i2c_set_cursor(0u, 0u);
lcd_i2c_write_string("System OK");
```

## Notes

- GPIO transport works in 4-bit transfer mode.
- I2C transport drives a PCF8574 backpack on the shared I2C master.
- Command/data timing relies on delay layer.

## Dependencies

- `core/compiler.h`
- `core/types.h`
- `core/delay.h`
- `drivers/communication/i2c/i2c.h` (I2C transport)
