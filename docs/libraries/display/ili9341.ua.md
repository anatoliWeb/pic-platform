# Бібліотека ILI9341 TFT

## Опис

`ili9341` — універсальний SPI backend для кольорових TFT-дисплеїв у pic-platform.
Бібліотека використовує ту саму lightweight direct-render архітектуру, що і `st7735`, та інтегрується з `graphics`, `bitmap`, `sprite_buffer`, `display_framework`.

## Публічний API

- `ili9341_init()`
- `ili9341_clear()`
- `ili9341_update()`
- `ili9341_draw_pixel()`
- `ili9341_fill_rect()`
- `ili9341_set_rotation()`
- `ili9341_draw_bitmap()` (опційно)
- `ili9341_blit_sprite()` (опційно)
- `ili9341_set_window()` (опційно)
- `ili9341_get_display_driver()`

## Архітектура Framebuffer / Update

- За замовчуванням direct rendering (без повного framebuffer 240x320).
- Запис пікселів і прямокутників виконується через SPI window transfers.
- `ili9341_update()` у direct режимі нічого не робить.
- Архітектура підготовлена для partial updates та dirty-region оптимізації на вищому рівні.

## Модель Дисплея

- Базовий розмір: 240x320
- Колірний формат: RGB565
- Rotation: 0/90/180/270 через MADCTL remap

## Нотатки по SPI

- Підтримується лише SPI
- Керуючі лінії через GPIO:
  - CS
  - DC
  - RESET
- Використовуються лише існуючі `drivers/communication/spi` та `drivers/gpio`.

## Нотатки по Інтеграції з Graphics

- Рендеринг символів у `display_framework` проходить через `graphics_draw_char()` з callback-виводом пікселів.
- Bitmap/sprite helper-и реалізовані як thin wrappers над `bitmap_t` та `sprite_t`.
- Рендеринг збережено lightweight для PIC-платформ.

## ST7735 vs ILI9341

- ILI9341 орієнтований на більший екран (240x320).
- Команди та init sequence відрізняються.
- Спільна архітектура: direct render, window writes, RGB565 helpers, модель rotation.

## Пам'ять / Продуктивність

- Без dynamic memory
- Лише integer-логіка
- Невеликий RAM footprint
- Підходить для PIC, де full TFT framebuffer занадто важкий

## Залежності

- `core/*`
- `drivers/communication/spi`
- `drivers/gpio`
- `libraries/display/graphics`
- `libraries/display/display_framework`
- `libraries/ui/sprite_buffer`
