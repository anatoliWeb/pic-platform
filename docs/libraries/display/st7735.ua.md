# Бібліотека ST7735 TFT

## Опис

`st7735` — універсальний SPI backend для кольорових TFT-дисплеїв у pic-platform.
На рівні API бібліотека інтегрується з `graphics`, `bitmap`, `sprite_buffer` та `display_framework`.

## Публічний API

- `st7735_init()`
- `st7735_clear()`
- `st7735_update()`
- `st7735_draw_pixel()`
- `st7735_fill_rect()`
- `st7735_set_rotation()`
- `st7735_draw_bitmap()` (опційно)
- `st7735_blit_sprite()` (опційно)
- `st7735_set_window()` (опційно)
- `st7735_get_display_driver()`

## Архітектура Framebuffer / Update

- За замовчуванням використовується **direct rendering** (без full-screen framebuffer).
- `st7735_draw_pixel()` і `st7735_fill_rect()` пишуть у вікно дисплея через SPI.
- `st7735_update()` у direct режимі нічого не робить.
- Архітектура підготовлена для partial-buffer та dirty-region розширень.

## Кольорова Модель

- Формат RGB565
- Макрос: `ST7735_COLOR565(r,g,b)`
- Доступні базові кольори (`BLACK`, `WHITE`, `RED` тощо)

## Транспорт і Керуючі Лінії

- Тільки SPI
- Використовуються існуючі драйвери:
  - `drivers/communication/spi`
  - `drivers/gpio`
- Налаштовувані лінії:
  - `CS`, `DC`, `RESET`

## Rotation

Підтримуються:

- `ST7735_ROT_0`
- `ST7735_ROT_90`
- `ST7735_ROT_180`
- `ST7735_ROT_270`

Всередині оновлюється MADCTL і логічні `width/height`.

## Нотатки по Інтеграції з Graphics

- Для тексту backend використовує graphics core (`graphics_draw_char` через callback).
- Для bitmap/sprite є helper-функції без дублювання логіки на верхньому рівні.
- `st7735_get_display_driver()` надає callbacks для display framework.

## Нотатки по Пам'яті / Продуктивності

- Без dynamic memory
- Лише integer-логіка
- Низьке споживання RAM (підходить для PIC)
- Підходить для lightweight UI і direct rendering

## Залежності

- `core/*`
- `drivers/communication/spi`
- `drivers/gpio`
- `libraries/display/graphics`
- `libraries/display/display_framework`
- `libraries/ui/sprite_buffer` (опційні helper-и)
