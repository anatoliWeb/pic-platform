# LCD HD44780 Драйвер

## Опис

GPIO-драйвер LCD HD44780 у 4-бітному режимі.
Надає ініціалізацію, керування курсором і вивід тексту.

## API

- `lcd_init_pins()`
- `lcd_init()`
- `lcd_clear()`
- `lcd_set_cursor()`
- `lcd_write_char()`
- `lcd_write_string()`

## Приклад

```c
lcd_init_pins(&PORTD, &TRISD, &PORTC, &TRISC, 0u, &PORTC, &TRISC, 1u, 4u, 5u, 6u, 7u);
lcd_init();
lcd_set_cursor(0u, 0u);
lcd_write_string("System OK");
```

## Особливості

- Працює у 4-бітному режимі передачі.
- Таймінги команд/даних залежать від шару delay.
