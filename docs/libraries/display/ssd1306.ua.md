# Бібліотека SSD1306

## Опис

`ssd1306` — універсальна бібліотека монохромного графічного OLED-дисплея на базі SSD1306.
Реалізована як backend, сумісний з `display_framework`.

## Публічний API

- `ssd1306_init()`
- `ssd1306_clear()`
- `ssd1306_update()`
- `ssd1306_draw_pixel()`
- `ssd1306_draw_char()`
- `ssd1306_draw_string()`
- `ssd1306_draw_line()` (опційно)
- `ssd1306_draw_rect()` (опційно)
- `ssd1306_draw_bitmap()` (опційно)
- `ssd1306_get_display_driver()`

## Архітектура Framebuffer

- Використовується внутрішній 1-бітний framebuffer.
- Максимальний розмір буфера: 1024 байти (128x64).
- Використовується сторінкова адресація SSD1306 (`y/8` сторінки, колонки по X).
- Операції малювання змінюють лише RAM.
- `ssd1306_update()` виконує flush на дисплей.

Це прибирає повільні I2C-записи для кожного пікселя.

## Підтримувані Розміри

- 128x64
- 128x32

Архітектура підготовлена до майбутньої сумісності з SH1106.

## Транспорт

- I2C режим реалізовано і використовується як основний.
- SPI режим залишено в API як підготовку на майбутнє.
- Типові I2C адреси: `0x3C` або `0x3D`.

## Підтримка Шрифту

- Вбудований ASCII шрифт 5x7 (`0x20..0x7F`).
- Легкий fixed-width рендеринг тексту.

## Інтеграція з display_framework

Використовуйте адаптер:

- `ssd1306_get_display_driver()`

Функція заповнює callbacks `display_driver_t`, після чого SSD1306 можна підключати через `display_init()`.

## Використання Пам'яті

- 128x64: 1024 байти framebuffer
- 128x32: 512 байт активної області (масив з запасом 1024 байти для переносимості)

## Обмеження

- Лише монохромний рендеринг 1-bit
- Без anti-aliasing
- Без variable fonts у поточній версії

## Залежності

- `core/*`
- `drivers/communication/i2c`
- `libraries/display/display_framework`
