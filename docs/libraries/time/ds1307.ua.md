# Бібліотека DS1307 RTC

## Опис

`ds1307` — легкий I2C backend для DS1307 з прямою інтеграцією в `rtc_framework`.
Підтримує роботу з datetime і опційні helper-и для RAM DS1307.

## Публічний API

- `ds1307_init()`
- `ds1307_set_datetime()`
- `ds1307_get_datetime()`
- `ds1307_get_driver()`
- `ds1307_set_ram()` (опційно)
- `ds1307_get_ram()` (опційно)

## Нотатки по інтеграції backend

Підключення до `rtc_framework`:

```c
ds1307_t chip;
rtc_t rtc;
ds1307_init(&chip, 0x68);
rtc_init(&rtc, ds1307_get_driver(), &chip);
```

Після цього працюють загальні `rtc_*` API.

## Нотатки по BCD

DS1307 зберігає дату/час у BCD.
У бібліотеці реалізовано:

- binary -> BCD для запису
- BCD -> binary для читання

Мапінг року:

- двозначний рік DS1307 -> `2000..2099`

Weekday:

- узгоджений з `rtc_datetime_t.weekday` (`1..7`).

## Обробка CH біта

Біт 7 у секундах — `CH` (clock halt):

- `CH = 1` означає зупинений генератор
- `ds1307_get_datetime()` повертає `DS1307_STATUS_OSCILLATOR_HALTED`

При встановленні часу CH очищається.

## Підтримка регістрів

- Time/date (`0x00..0x06`)
- Control (`0x07`)
- Опційно RAM (`0x08..0x3F`)

Архітектура готова до майбутніх helper-ів square-wave/control.

## Нотатки про backup battery

За наявності backup battery DS1307 може зберігати час при втраті живлення.
Якщо після старту CH встановлений, час треба перевстановити.
