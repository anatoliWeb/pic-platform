# DS12C887 RTC Library

## Description

`ds12c887` is a lightweight backend for DS12C887/PC-style RTC using indexed register access.
It integrates with `rtc_framework` and uses GPIO only.

## Public API

- `ds12c887_init()`
- `ds12c887_set_datetime()`
- `ds12c887_get_datetime()`
- `ds12c887_get_driver()`
- `ds12c887_read_cmos()` (optional helper)
- `ds12c887_write_cmos()` (optional helper)
- `ds12c887_enable_periodic_irq()` (optional helper)

## Indexed Access Implementation Notes

The device uses:

- address/index register bus
- data register bus
- control lines (`CS`, `AS`, `DS`, `RW`)

Library sequence:

1. put index on address bus
2. pulse address strobe
3. read/write data bus with data strobe

All operations are bit-banged through GPIO.

## Backend Integration Notes

Use with framework:

```c
ds12c887_t chip;
rtc_t rtc;
ds12c887_init(&chip);
rtc_init(&rtc, ds12c887_get_driver(), &chip);
```

Then generic `rtc_*` APIs operate on DS12C887.

## BCD and Mode Notes

- Supports BCD conversion helpers.
- Handles both BCD mode and binary mode (via Register B `DM` bit).
- Uses 24-hour format.
- Century is read/written through configurable CMOS index (default `0x32`).

## UIP Handling

Register A `UIP` bit is checked before reads.
If update-in-progress does not clear within timeout, `DS12C887_STATUS_UIP_TIMEOUT` is returned.

## CMOS RAM and Control Notes

- Generic CMOS read/write helpers are available.
- Prepared for future alarm IRQ, periodic IRQ, and square-wave related controls.

## Battery Backup and PC RTC Context

DS12C887 is PC-compatible RTC/CMOS style hardware with backup battery domain.
If battery is weak or invalid state occurs, time data may need reinitialization.

## Dependencies

- `core/*`
- `drivers/gpio`
- `libraries/time/rtc_framework`
