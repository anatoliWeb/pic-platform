# Бібліотека DS12C887 RTC

## Опис

`ds12c887` — легкий backend для DS12C887/PC-сумісного RTC з indexed register access.
Інтегрується з `rtc_framework` і використовує тільки GPIO.

## Публічний API

- `ds12c887_init()`
- `ds12c887_set_datetime()`
- `ds12c887_get_datetime()`
- `ds12c887_get_driver()`
- `ds12c887_read_cmos()` (опційно)
- `ds12c887_write_cmos()` (опційно)
- `ds12c887_enable_periodic_irq()` (опційно)

## Нотатки по indexed access

Модель доступу:

- address/index bus
- data bus
- керуючі лінії (`CS`, `AS`, `DS`, `RW`)

Послідовність:

1. виставити index на address bus
2. дати імпульс address strobe
3. читати/писати data bus через data strobe

Усе реалізовано bit-banged через GPIO.

## Нотатки по інтеграції backend

Підключення до framework:

```c
ds12c887_t chip;
rtc_t rtc;
ds12c887_init(&chip);
rtc_init(&rtc, ds12c887_get_driver(), &chip);
```

Після цього працюють загальні `rtc_*` API.

## BCD та режими

- Є BCD helper-и.
- Підтримані BCD mode і binary mode (через `DM` в Register B).
- Використовується 24-hour формат.
- Century читається/пишеться через налаштований CMOS index (типово `0x32`).

## UIP обробка

Перед читанням перевіряється `UIP` біт у Register A.
Якщо UIP не очищається в межах timeout, повертається `DS12C887_STATUS_UIP_TIMEOUT`.

## CMOS RAM та control

- Доступні helper-и для CMOS read/write.
- Архітектура підготовлена для alarm IRQ, periodic IRQ, square-wave функцій.

## Battery backup та історичний контекст

DS12C887 — PC-style RTC/CMOS з backup battery доменом.
При слабкій батареї або невалідному стані може знадобитись повторна ініціалізація часу.
