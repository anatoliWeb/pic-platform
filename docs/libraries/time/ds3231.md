# DS3231 RTC Library

## Description

`ds3231` is a lightweight RTC backend library for DS3231 over I2C.
It integrates directly with `rtc_framework` through `rtc_driver_t`.

## Public API

- `ds3231_init()`
- `ds3231_set_datetime()`
- `ds3231_get_datetime()`
- `ds3231_get_temperature()`
- `ds3231_get_driver()`

## Backend Integration

Use with framework:

1. Initialize DS3231 context.
2. Pass backend driver to `rtc_init()`.

```c
ds3231_t chip;
rtc_t rtc;
ds3231_init(&chip, 0x68);
rtc_init(&rtc, ds3231_get_driver(), &chip);
```

After that, generic `rtc_*` APIs work with DS3231 hardware.

## BCD Conversion Notes

DS3231 stores time/date in BCD.
Library uses helpers:

- binary -> BCD for writes
- BCD -> binary for reads

Handled fields:

- seconds, minutes, hours
- weekday, day, month, year

Year is mapped to 2000-based range (`2000..2099`).

## Register Coverage

- Time/date registers (`0x00..0x06`)
- Control/status registers (`0x0E`, `0x0F`)
- Temperature registers (`0x11`, `0x12`)

Architecture is prepared for future alarm/square-wave extensions.

## Temperature Support

`ds3231_get_temperature()` reads internal sensor and returns `temperature_x10`.
No floating-point math is used.

## Error Handling

Library detects:

- I2C communication errors
- invalid datetime data after decode
- oscillator stop flag (`OSF`) condition

If OSF is set, read returns `DS3231_STATUS_OSCILLATOR_STOPPED`.

## Backup Battery Notes

With backup battery, DS3231 keeps time during main power loss.
After first power-up or brownout events, check OSF and reinitialize time if needed.

## Dependencies

- `core/*`
- `drivers/communication/i2c`
- `libraries/time/rtc_framework`
