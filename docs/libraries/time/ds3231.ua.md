# Бібліотека DS3231 RTC

## Опис

`ds3231` — легка бібліотека backend для DS3231 по I2C.
Інтегрується з `rtc_framework` через `rtc_driver_t`.

## Публічний API

- `ds3231_init()`
- `ds3231_set_datetime()`
- `ds3231_get_datetime()`
- `ds3231_get_temperature()`
- `ds3231_get_driver()`

## Інтеграція з backend

Схема інтеграції:

1. Ініціалізувати DS3231 контекст.
2. Передати backend driver у `rtc_init()`.

```c
ds3231_t chip;
rtc_t rtc;
ds3231_init(&chip, 0x68);
rtc_init(&rtc, ds3231_get_driver(), &chip);
```

Після цього можна використовувати загальні `rtc_*` API.

## Нотатки по BCD

DS3231 зберігає дату/час у BCD форматі.
Бібліотека має helper-и:

- binary -> BCD для запису
- BCD -> binary для читання

Поля:

- seconds, minutes, hours
- weekday, day, month, year

Рік мапиться у діапазон 2000..2099.

## Підтримка регістрів

- Регістри часу/дати (`0x00..0x06`)
- Регістри control/status (`0x0E`, `0x0F`)
- Температурні регістри (`0x11`, `0x12`)

Архітектура підготовлена для майбутніх alarm/square-wave розширень.

## Температура

`ds3231_get_temperature()` читає внутрішній сенсор DS3231 і повертає `temperature_x10`.
Без floating-point обчислень.

## Обробка помилок

Виявляються:

- помилки I2C
- невалідні datetime після декодування
- стан `OSF` (oscillator stop flag)

Якщо `OSF` встановлений, читання повертає `DS3231_STATUS_OSCILLATOR_STOPPED`.

## Нотатки про backup battery

З backup battery DS3231 зберігає час при зникненні основного живлення.
Після першого старту або brownout бажано перевірити OSF і за потреби перевстановити час.
