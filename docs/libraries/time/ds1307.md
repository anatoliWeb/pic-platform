# DS1307 RTC Library

## Description

`ds1307` is a lightweight I2C RTC backend for DS1307 with direct `rtc_framework` integration.
It supports datetime access and optional DS1307 RAM usage helpers.

## Public API

- `ds1307_init()`
- `ds1307_set_datetime()`
- `ds1307_get_datetime()`
- `ds1307_get_driver()`
- `ds1307_set_ram()` (optional helper)
- `ds1307_get_ram()` (optional helper)

## Backend Integration Notes

Use with `rtc_framework`:

```c
ds1307_t chip;
rtc_t rtc;
ds1307_init(&chip, 0x68);
rtc_init(&rtc, ds1307_get_driver(), &chip);
```

After this, generic `rtc_*` APIs can control DS1307.

## BCD Conversion Notes

DS1307 stores date/time in BCD.
Library implements:

- binary -> BCD for writes
- BCD -> binary for reads

Year mapping:

- two-digit DS1307 year -> `2000..2099`

Weekday:

- mapped with `rtc_datetime_t.weekday` range `1..7`.

## CH Bit Handling

Seconds register bit 7 is `CH` (clock halt):

- `CH = 1` means oscillator halted
- `ds1307_get_datetime()` returns `DS1307_STATUS_OSCILLATOR_HALTED` when detected

When setting datetime, CH is cleared to start clock.

## Register Coverage

- Time/date registers (`0x00..0x06`)
- Control register (`0x07`)
- Optional RAM block (`0x08..0x3F`)

Prepared for future square-wave/control helpers.

## Backup Battery Notes

With backup battery, DS1307 keeps running on power loss.
If CH is set after startup, time should be reinitialized.
