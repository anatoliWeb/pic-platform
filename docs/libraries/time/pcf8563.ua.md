# Бібліотека PCF8563 RTC

## Опис

`pcf8563` — легкий backend RTC по I2C для PCF8563.
Інтегрується з `rtc_framework` через callbacks `rtc_driver_t`.

## Публічний API

- `pcf8563_init()`
- `pcf8563_set_datetime()`
- `pcf8563_get_datetime()`
- `pcf8563_get_driver()`
- `pcf8563_set_alarm()` (опційно)
- `pcf8563_clear_alarm()` (опційно)

## Інтеграція з backend

Приклад інтеграції:

```c
pcf8563_t chip;
rtc_t rtc;
pcf8563_init(&chip, 0x51);
rtc_init(&rtc, pcf8563_get_driver(), &chip);
```

Після цього доступні загальні API з `rtc_framework`.

## Нотатки по BCD

Регістри часу/дати PCF8563 використовують BCD.
Бібліотека виконує:

- binary -> BCD при записі
- BCD -> binary при читанні

Поля:

- seconds, minutes, hours
- day, weekday, month, year

Рік мапиться в діапазон `2000..2099`.

## Огляд регістрів

Покриті регістри:

- control/status (`0x00`, `0x01`)
- datetime (`0x02..0x08`)
- alarm (`0x09..0x0C`)

Архітектура підготовлена для майбутнього:

- alarm interrupt
- countdown timer

## Voltage Low Flag

Біт `VL` (біт 7 у секундах) сигналізує про можливу втрату валідності часу.
Бібліотека повертає `PCF8563_STATUS_VOLTAGE_LOW`.

## Нотатки про backup battery

Використовуйте backup живлення за рекомендаціями hardware.
Після brownout/перемикань перевіряйте `VL` і при потребі задавайте час повторно.
