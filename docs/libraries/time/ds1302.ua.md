# Бібліотека DS1302 RTC

## Опис

`ds1302` — легкий RTC backend для DS1302 з рідним 3-wire протоколом.
Бібліотека інтегрується з `rtc_framework` і не використовує I2C/SPI драйвери.

## Публічний API

- `ds1302_init()`
- `ds1302_set_datetime()`
- `ds1302_get_datetime()`
- `ds1302_get_driver()`
- `ds1302_write_ram()` (опційно)
- `ds1302_read_ram()` (опційно)
- `ds1302_enable_write_protect()` (опційно)
- `ds1302_disable_write_protect()` (опційно)

## Нотатки по реалізації протоколу

Лінії DS1302:

- `CE`
- `CLK`
- `IO` (двонапрямна)

Бібліотека реалізує bit-banged обмін:

- LSB-first передача command/data
- перемикання напрямку IO для read/write
- робота через register command байти

Без додаткових стеків.

## Нотатки по інтеграції backend

Підключення до framework:

```c
ds1302_t chip;
rtc_t rtc;
ds1302_init(&chip);
rtc_init(&rtc, ds1302_get_driver(), &chip);
```

Після цього доступні загальні `rtc_*` API.

## Нотатки по BCD

Поля часу DS1302 зберігаються у BCD.
У бібліотеці є:

- binary -> BCD
- BCD -> binary

Рік:

- `00..99` -> `2000..2099`

Weekday:

- `rtc_datetime_t.weekday` у діапазоні `1..7`.

## CH / Write Protect

- Біт `CH` у секундах (біт 7):
  - якщо встановлений, повертається `DS1302_STATUS_CLOCK_HALTED`.
- Write protect біт (WP):
  - перед записом WP вимикається, після запису вмикається.

## Нотатки про RAM

- Підтримані helper-и для RAM DS1302.
- Доступні offset-и `0..30`.
