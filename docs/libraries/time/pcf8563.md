# PCF8563 RTC Library

## Description

`pcf8563` is a lightweight I2C RTC backend for PCF8563.
It integrates directly with `rtc_framework` using `rtc_driver_t` callbacks.

## Public API

- `pcf8563_init()`
- `pcf8563_set_datetime()`
- `pcf8563_get_datetime()`
- `pcf8563_get_driver()`
- `pcf8563_set_alarm()` (optional helper)
- `pcf8563_clear_alarm()` (optional helper)

## Backend Integration

Use as framework backend:

```c
pcf8563_t chip;
rtc_t rtc;
pcf8563_init(&chip, 0x51);
rtc_init(&rtc, pcf8563_get_driver(), &chip);
```

Then standard `rtc_framework` API can be used.

## BCD Conversion Notes

PCF8563 time/date registers use BCD format.
Library converts:

- binary -> BCD on writes
- BCD -> binary on reads

Handled fields:

- seconds, minutes, hours
- day, weekday, month, year

Year is mapped to `2000..2099`.

## Register Map Overview

Covered registers:

- control/status (`0x00`, `0x01`)
- datetime (`0x02..0x08`)
- alarm (`0x09..0x0C`)

Architecture is prepared for future:

- alarm interrupt flow
- countdown timer support

## Voltage Low Flag

Seconds register bit 7 is `VL`.
If set, clock integrity may be compromised.
Library reports this via `PCF8563_STATUS_VOLTAGE_LOW`.

## Backup Battery Notes

Use backup supply according to hardware design.
After brownout/backup transitions, check `VL` and reinitialize time if needed.
