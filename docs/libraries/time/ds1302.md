# DS1302 RTC Library

## Description

`ds1302` is a lightweight RTC backend for DS1302 using its native 3-wire serial protocol.
It integrates directly with `rtc_framework` and does not use I2C/SPI drivers.

## Public API

- `ds1302_init()`
- `ds1302_set_datetime()`
- `ds1302_get_datetime()`
- `ds1302_get_driver()`
- `ds1302_write_ram()` (optional)
- `ds1302_read_ram()` (optional)
- `ds1302_enable_write_protect()` (optional)
- `ds1302_disable_write_protect()` (optional)

## Protocol Implementation Notes

DS1302 interface lines:

- `CE`
- `CLK`
- `IO` (bidirectional)

Library implements bit-banged serial transfer:

- LSB-first command/data transfer
- GPIO direction switching for IO read/write
- register read/write through command bytes

No dynamic transport stack is required.

## Backend Integration Notes

Use with framework:

```c
ds1302_t chip;
rtc_t rtc;
ds1302_init(&chip);
rtc_init(&rtc, ds1302_get_driver(), &chip);
```

Then generic `rtc_*` APIs work with DS1302.

## BCD Conversion Notes

DS1302 time fields are BCD encoded.
Library includes:

- binary -> BCD conversion
- BCD -> binary conversion

Year mapping:

- DS1302 year (00..99) -> 2000..2099

Weekday mapping:

- `rtc_datetime_t.weekday` in `1..7`

## CH / Write Protect Handling

- Seconds register bit 7 is `CH` (clock halt).
  - if set, read returns `DS1302_STATUS_CLOCK_HALTED`.
- Write protect register bit 7 controls write access.
  - writes disable WP before update and restore it after.

## RAM Area Notes

- Optional DS1302 RAM helpers are supported.
- Addressable RAM offsets: `0..30`.

## Dependencies

- `core/*`
- `drivers/gpio`
- `libraries/time/rtc_framework`
