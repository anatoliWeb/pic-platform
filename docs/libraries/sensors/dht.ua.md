# Бібліотека DHT (DHT11 + DHT22)

## Опис

`dht` — уніфікована бібліотека для DHT11 і DHT22.
Тип сенсора задається через конфігурацію, тому один API працює для обох пристроїв.

## Публічний API

- `dht_init()`
- `dht_read()`
- `dht_get_temperature()` (масштаб x10)
- `dht_get_humidity()` (масштаб x10)
- `dht_is_valid()`

## Підтримувані типи сенсорів

- `DHT_SENSOR_DHT11`
- `DHT_SENSOR_DHT22`

## Модель даних

Бібліотека зберігає значення у вигляді:

- `temperature_x10` (наприклад `253` = 25.3C)
- `humidity_x10` (наприклад `615` = 61.5%)
- прапорець `valid`

## Таймінги і протокол

Реалізація виконує стандартний DHT обмін:

1. Стартовий імпульс хоста (`~18ms` для DHT11, `~1ms` для DHT22 за замовчуванням)
2. Відповідь сенсора
3. Зчитування 40-бітного кадру з декодуванням по ширині імпульсу
4. Перевірка checksum

Чутлива до таймінгів частина коду коротка і виконується в критичній секції.

## Обробка помилок

`dht_read()` повертає `dht_status_t`:

- `DHT_STATUS_OK`
- `DHT_STATUS_TIMEOUT`
- `DHT_STATUS_CHECKSUM`
- `DHT_STATUS_INVALID_FRAME`
- `DHT_STATUS_TOO_SOON`
- `DHT_STATUS_ERROR`

## Різниця DHT11 vs DHT22

- DHT11: нижча точність, переважно цілі значення, коротший інтервал.
- DHT22: вища точність, signed температура, рекомендований інтервал 2с.

## Підключення

- Лінія даних потребує pull-up резистора (типово 4.7k до VCC).
- Бажано коротка лінія і мінімум перешкод.
- GPIO пін має перемикатись між input/output.

## Обмеження по частоті читання

- DHT11: інтервал за замовчуванням 1 секунда
- DHT22: інтервал за замовчуванням 2 секунди

Інтервали можна перевизначити у конфігурації.

## Залежності

- `core/*`
- `drivers/gpio`
- `drivers/timers/tick`
