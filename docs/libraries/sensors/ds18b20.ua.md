# DS18B20 Драйвер

## Опис

Драйвер температурного сенсора поверх OneWire API.
Підтримує запуск конверсії, читання scratchpad, CRC-перевірку та отримання температури.

## API

- `ds18b20_start_conversion()`
- `ds18b20_read_scratchpad()`
- `ds18b20_read_temperature_raw()`
- `ds18b20_read_temperature_celsius()`
- `ds18b20_get_temperature_raw()`
- `ds18b20_get_temperature_celsius_x10()`

## Приклад

```c
int16_t temp_x10;

if (ds18b20_start_conversion(0) != 0u)
{
    if (ds18b20_read_temperature_celsius(0, &temp_x10) != 0u)
    {
        // temp_x10 містить Celsius * 10
    }
}
```

## Особливості

- Використовує scratchpad дані з CRC-перевіркою.
- `*_celsius()` повертає fixed-point значення у форматі x10.
- Підтримується робота кількох датчиків на одній шині, якщо застосунок виконує ROM search і Match ROM flow.
- На спільній лінії DQ потрібен один підтягувальний резистор 4.7k до VDD.
