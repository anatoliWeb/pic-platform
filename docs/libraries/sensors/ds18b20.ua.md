# Драйвер DS18B20

## Опис

Драйвер температурного датчика поверх OneWire API.
Підтримує пошук ROM, режими Match ROM і Skip ROM, читання scratchpad,
перевірку CRC та fixed-point вивід температури.

## Модель таймінгів

- Reset, presence detect і read slots працюють у реальних мікросекундах.
- Write slots залежать від профілю.
- У validated preset для PIC18F452 + Proteus поля write працюють як raw
  tuning ticks, а не як реальні мікросекунди.
- Це зберігає робочий приклад без зміни public API.

## API

- `ds18b20_search()`
- `ds18b20_find_first()`
- `ds18b20_is_valid_family()`
- `ds18b20_is_valid_rom()`
- `ds18b20_start_conversion()`
- `ds18b20_start_conversion_skip_rom()`
- `ds18b20_read_scratchpad()`
- `ds18b20_read_scratchpad_skip_rom()`
- `ds18b20_read_temperature_raw()`
- `ds18b20_read_temperature_raw_skip_rom()`
- `ds18b20_read_temperature_celsius()`
- `ds18b20_read_temperature_celsius_skip_rom()`
- `ds18b20_get_temperature_raw()`
- `ds18b20_get_temperature_celsius_x10()`

## Приклад

```c
uint8_t rom[8];
int16_t temp_x10;

if (ds18b20_find_first(rom) != 0u)
{
    if (ds18b20_read_temperature_celsius(rom, &temp_x10) != 0u)
    {
        /* temp_x10 містить значення температури у форматі Celsius * 10. */
    }
}
else
{
    if (ds18b20_read_temperature_celsius_skip_rom(&temp_x10) != 0u)
    {
        /* Резервний режим Skip ROM для одного датчика. */
    }
}
```

## Особливості

- Використовує scratchpad із перевіркою CRC.
- `*_celsius()` повертає fixed-point значення у масштабі x10.
- Допоміжні функції пошуку ROM дозволяють працювати з кількома датчиками на
  одній шині 1-Wire.
- Допоміжні Skip ROM-функції зручні для одного датчика.
- На лінії DQ потрібен один підтягувальний резистор 4.7k до VDD.
