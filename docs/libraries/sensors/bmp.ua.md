# Бібліотека BMP (BMP180 + BMP280)

## Опис

`bmp` — уніфікована бібліотека для сенсорів тиску/температури BMP180 і BMP280.
Тип сенсора задається в конфігурації, API залишається єдиним.

## Публічний API

- `bmp_init()`
- `bmp_read()`
- `bmp_get_temperature()` (`x10` градусів C)
- `bmp_get_pressure()` (Па)
- `bmp_get_altitude()` (опційний helper, метри, наближено)
- `bmp_is_valid()`

## Підтримувані типи сенсорів

- `BMP_SENSOR_BMP180`
- `BMP_SENSOR_BMP280`

## Конфігурація

- `sensor_type`
- `i2c_address` (наприклад `0x77` або `0x76`)
- `oversampling` (використовується для BMP180)

## Калібрування і компенсація

### BMP180
- Зчитування calibration слів із `0xAA..0xBF`.
- Класичні integer формули компенсації температури і тиску.
- Oversampling `OSS` з конфігурації (`0..3`).

### BMP280
- Зчитування calibration блоку `0x88..0x9F`.
- Температура через `t_fine`.
- Тиск через fixed-point compensation ланцюг.

## Обробка помилок

Ініціалізація та `bmp_read()` визначають:

- помилки I2C
- некоректний chip ID
- некоректні calibration дані
- невалідні edge-case стани при компенсації

## Різниця BMP180 vs BMP280

- BMP180: старіший сенсор, інший register map і цикл конверсії.
- BMP280: новіший, інший набір calibration і формули.
- Уніфікована бібліотека приховує цю різницю одним API.

## Підключення і I2C

- Потрібні pull-up резистори на SDA/SCL.
- Типові адреси:
  - BMP180: зазвичай `0x77`
  - BMP280: `0x76` або `0x77` (залежить від SDO)

## Залежності

- `core/*`
- `drivers/communication/i2c`

## Обмеження

- `bmp_get_altitude()` використовує легку лінійну апроксимацію (не повна барометрична формула).
- Для високої точності висоти краще використовувати повну формулу/фільтрацію на рівні application.
