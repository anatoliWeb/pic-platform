# DS18B20 Driver

## Description

Temperature sensor driver built on top of the OneWire API.
Supports ROM search, Match ROM and Skip ROM flows, scratchpad read, CRC check,
and fixed-point temperature output.

## Timing Model

- Reset, presence detect, and read slots use real microseconds.
- Write slots are profile-dependent.
- In the validated PIC18F452 Proteus preset, write fields behave as raw tuning
  ticks, not as real microseconds.
- This keeps the working example stable without changing the public API.

## API

- `ds18b20_search()`
- `ds18b20_find_first()`
- `ds18b20_is_valid_family()`
- `ds18b20_is_valid_rom()`
- `ds18b20_start_conversion()`
- `ds18b20_start_conversion_skip_rom()`
- `ds18b20_read_scratchpad()`
- `ds18b20_read_scratchpad_skip_rom()`
- `ds18b20_read_temperature_raw()`
- `ds18b20_read_temperature_raw_skip_rom()`
- `ds18b20_read_temperature_celsius()`
- `ds18b20_read_temperature_celsius_skip_rom()`
- `ds18b20_get_temperature_raw()`
- `ds18b20_get_temperature_celsius_x10()`

## Example

```c
uint8_t rom[8];
int16_t temp_x10;

if (ds18b20_find_first(rom) != 0u)
{
    if (ds18b20_read_temperature_celsius(rom, &temp_x10) != 0u)
    {
        /* temp_x10 contains Celsius * 10. */
    }
}
else
{
    if (ds18b20_read_temperature_celsius_skip_rom(&temp_x10) != 0u)
    {
        /* Single-sensor Skip ROM fallback. */
    }
}
```

## Notes

- Uses scratchpad data with CRC validation.
- `*_celsius()` returns a fixed-point value in x10 scale.
- ROM search helpers allow multi-sensor use on one shared 1-Wire bus.
- Skip ROM helpers are convenient for a single-sensor setup.
- A single 4.7k pull-up resistor is required on the shared DQ line.
