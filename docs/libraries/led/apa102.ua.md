# Бібліотека APA102 / DotStar

## Опис

`apa102` — легка SPI-бібліотека керування адресними LED APA102/DotStar.
Надає повторно використовуваний framebuffer API у стилі інших LED модулів платформи.

## Публічний API

- `apa102_init()`
- `apa102_set_pixel()`
- `apa102_set_all()`
- `apa102_clear()`
- `apa102_show()`
- `apa102_set_brightness()`

## Нотатки по протоколу

Послідовність кадру APA102:

1. Start frame: 4 байти `0x00`.
2. LED frames: `0b111xxxxx, B, G, R`.
3. End frame: додаткові тактові байти (бібліотека шле `(led_count + 15) / 16` байт `0xFF`).

Реалізація використовує лише існуючий SPI-драйвер (`spi_transfer_byte`).

## Модель кольору та яскравості

- Колір подається через `rgb_color_t` з `rgb_utils`.
- Пер-піксельна яскравість 5-bit зберігається у framebuffer (`0..31`).
- Глобальна яскравість (`0..255`) масштабує RGB перед передачею.

## Модель пам'яті

- Без dynamic allocation.
- Буфер (`apa102_pixel_t[]`) передається користувачем у `apa102_init()`.
- Бібліотека зберігає лише посилання і простий стан.

## Підключення

- `DATA` і `CLK` підключати до SPI-пінів.
- Спільна земля між MCU і живленням стрічки обов'язкова.
- Для довгих стрічок бажано power injection і конденсатори.

## APA102 vs WS2812

- APA102 тактований, зазвичай простіший для стабільного керування на PIC18.
- WS2812 вимагає дуже точних single-wire таймінгів.
- APA102 зазвичай краще масштабується на довгі ланцюги.
