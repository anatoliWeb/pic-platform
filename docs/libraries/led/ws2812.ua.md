# Бібліотека WS2812 / WS2812B

## Опис
Перевикористовувана бібліотека для адресних RGB LED WS2812/WS2812B.
Орієнтована на PIC18 з детермінованою генерацією bitstream.

## Публічний API
- `ws2812_init()`
- `ws2812_set_pixel()`
- `ws2812_set_all()`
- `ws2812_clear()`
- `ws2812_set_brightness()`
- `ws2812_show()`

## Підтримувані цілі
- WS2812
- WS2812B
- налаштовувана кількість LED
- база для стрічок, кілець і матриць

## Нотатки по таймінгу
- WS2812 має жорсткі вимоги до one-wire таймінгу.
- Передача зроблена в таймінг-критичних циклах.
- На час `ws2812_show()` переривання вимикаються для стабільного сигналу.
- Поточна реалізація використовує loop-based таймінг, який може потребувати калібрування під Fosc.

## Приклад підключення
- GPIO MCU (data) -> DIN першого LED
- спільна земля MCU і БЖ стрічки
- +5V на живлення стрічки (або згідно datasheet)
- бажано ~330R послідовно в data-лінії біля DIN

## Живлення
- Струм може бути значним: до ~60mA на LED при білому.
- Для середніх/довгих стрічок потрібне зовнішнє живлення.
- Додайте ємність біля входу стрічки (наприклад 470uF+).

## Level shifting
- Більшість WS2812 очікують 5V-рівні керування.
- Якщо MCU на 3.3V, може знадобитись level shifter.

## Модель RAM
- Бібліотека використовує буфер, який передає користувач: `led_count * sizeof(ws2812_color_t)`.
- `ws2812_color_t` = 3 байти (R,G,B).
- Динамічна пам'ять не використовується.

## Обмеження PIC18
- Таймінг bit-bang залежить від компілятора, оптимізації та тактової частоти.
- Довгі стрічки збільшують blocking-час `ws2812_show()`.
- Для критичних задач може знадобитись ручне ASM-тюнінгування.

## Залежності
- `core/*`
- `drivers/gpio/*`
