# Бібліотека RGB Utilities

## Опис
Перевикористовувана бібліотека кольорових утиліт для LED-систем.
Містить легкі integer-операції для RGB/HSV на embedded-платформах.

## Публічний API
- `rgb_color()`
- `rgb_scale()`
- `rgb_blend()`
- `rgb_add()`
- `rgb_subtract()`
- `hsv_to_rgb()`

## Підтримувані моделі кольору
- RGB (`rgb_color_t`)
- HSV (`hsv_color_t`)

## Нотатки щодо integer math
- Усі обчислення виконуються тільки цілими числами.
- Залежності від floating point немає.
- Проміжні значення рахуються у 16-бітному форматі для уникнення overflow.

## Масштабування яскравості
- `rgb_scale(color, scale)` масштабує яскравість у діапазоні `0..255`.
- `0` = вимкнено, `255` = без змін.

## Змішування
- `rgb_blend(a, b, alpha)` виконує лінійну інтерполяцію:
  - `alpha=0` -> `a`
  - `alpha=255` -> `b`

## Додаткові хелпери
- `rgb_add()` із saturation до 255.
- `rgb_subtract()` із обмеженням знизу до 0.

## Embedded-оптимізація
- Без динамічної пам'яті.
- Мінімальне використання стека.
- Підходить як база для ефектів, матриць і animation engine.

## Залежності
- тільки `core/*`
