# APA102 / DotStar Library

## Description

`apa102` is a lightweight SPI-based addressable LED library for APA102/DotStar.
It provides a reusable framebuffer API similar to other LED modules in pic-platform.

## Public API

- `apa102_init()`
- `apa102_set_pixel()`
- `apa102_set_all()`
- `apa102_clear()`
- `apa102_show()`
- `apa102_set_brightness()`

## Protocol Notes

APA102 frame sequence:

1. Start frame: 4 bytes `0x00`.
2. LED frames: `0b111xxxxx, B, G, R`.
3. End frame: extra clock bytes (library sends `(led_count + 15) / 16` bytes of `0xFF`).

The implementation uses only the existing SPI driver (`spi_transfer_byte`).

## Color and Brightness Model

- Color input uses `rgb_color_t` from `rgb_utils`.
- Per-pixel 5-bit brightness is stored in framebuffer (`0..31`).
- Global brightness (`0..255`) scales RGB channels before transmission.

## Memory Model

- No dynamic allocation.
- User provides framebuffer (`apa102_pixel_t[]`) to `apa102_init()`.
- Library stores only references and simple state.

## Wiring Notes

- Connect `DATA` and `CLK` to SPI-capable pins.
- Share ground between MCU and LED power source.
- For long strips, inject power and use decoupling capacitors.

## APA102 vs WS2812

- APA102 is clocked and generally easier for deterministic timing on PIC18.
- WS2812 needs strict single-wire bit timing.
- APA102 usually tolerates longer chains and higher refresh rates.

## Dependencies

- `core/*`
- `drivers/communication/spi`
- `libraries/led/rgb_utils`
