# WS2812 / WS2812B Library

## Description
Reusable addressable RGB LED library for WS2812/WS2812B strips and modules.
Designed for PIC18-class MCUs with deterministic bitstream output.

## Public API
- `ws2812_init()`
- `ws2812_set_pixel()`
- `ws2812_set_all()`
- `ws2812_clear()`
- `ws2812_set_brightness()`
- `ws2812_show()`

## Supported Targets
- WS2812
- WS2812B
- configurable LED count
- suitable base for strips, rings, and matrices

## Timing Notes
- WS2812 uses strict one-wire timing.
- Bitstream output is done in timing-critical loops.
- Interrupts are disabled during `ws2812_show()` to keep waveform deterministic.
- Current implementation uses conservative loop-based timing that may need calibration per Fosc.

## Wiring Example
- MCU GPIO data pin -> DIN of first LED
- GND shared between MCU and LED power supply
- +5V to strip power (or per LED datasheet)
- Optional 330R resistor in data line near LED DIN

## Power Considerations
- Current can be high: up to ~60mA per LED at full white.
- Use external power supply for medium/large strips.
- Add bulk capacitor near strip input (for example 470uF+).

## Level Shifting
- Many WS2812 strips are 5V logic-oriented.
- If MCU is 3.3V, a level shifter may be required for reliable signal integrity.

## RAM Usage Model
- Library uses user-provided framebuffer: `led_count * sizeof(ws2812_color_t)`.
- `ws2812_color_t` is 3 bytes (R,G,B).
- No dynamic memory allocation is used.

## PIC18 Limitations
- Bit-bang timing depends on compiler optimization and clock.
- Very long strips increase blocking time inside `ws2812_show()`.
- Time-critical applications may require dedicated assembly tuning.

## Dependencies
- `core/*`
- `drivers/gpio/*`
