# Гайд З Портування

## Що Копіювати
- `core/`
- Потрібні папки з `drivers/`
- За потреби C18/XC8 override-реалізації

## Кроки
1. Обрати цільовий MCU у проєкті
2. Налаштувати `DRV_XTAL_FREQ`
3. Додати include paths
4. Зібрати та перевірити приклади

## Чекліст
- Немає хардкоду пінів під конкретну плату
- Config bits відповідають платі
- Таймінги UART/I2C узгоджені з частотою
