# Naming Rules

## Functions
- Format: `driver_action()`
- Examples: `uart_init`, `gpio_set_output`, `adc_read`

## Types
- Structures: `<driver>_t`
- Enums: `<driver>_<name>_t`

## Macros
- Prefix: `DRV_`
- Style: `UPPER_SNAKE_CASE`

## Files
- Lowercase file names
- Header/source names match driver name
