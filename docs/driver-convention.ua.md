# Конвенція Драйверів

## Призначення
Документ задає єдиний стандарт для всіх драйверів платформи.

## Обов'язкова Структура Драйвера
- `drivers/<name>/<name>.h`
- `drivers/<name>/<name>.c`
- `drivers/<name>/example.c`

## Правила API
- API має бути мінімальним і зрозумілим.
- Формат імен: `driver_action()`.
- У `.h` лише публічні декларації.

## Обмеження
- Без project-specific логіки у драйверах.
- Без хардкоду пінів, якщо їх не передано через init/config.
- Без динамічної пам'яті (`malloc`/`free`).

## Розділення За Компіляторами
- Спільна логіка: `drivers/<name>/`
- C18-реалізація: `C18/drivers/<name>/`
- XC8-реалізація: `XC8/drivers/<name>/`
- Спільна абстракція: `core/compiler.h`
