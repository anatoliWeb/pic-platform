# Гайд По Прикладах

## Рівні Прикладів
- Локальний приклад драйвера: `drivers/<name>/example.c`
- Універсальні приклади: `examples/common/`
- Приклади за компіляторами: `C18/examples/`, `XC8/examples/`

## Порядок Перевірки
1. Спочатку збирати прості приклади (GPIO/UART)
2. Далі збирати приклад цільового драйвера
3. Потім збирати compiler-specific приклади

## Правила
- Мінімальні приклади
- Показувати init + базове API
- Не додавати бізнес-логіку
