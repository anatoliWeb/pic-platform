# Валідація Збірки

У цьому середовищі немає toolchain, тому перевірка виконується вручну в MPLAB.

## C18
1. Відкрити проєкт у MPLAB IDE з C18
2. Спочатку зібрати базові приклади (`gpio`, `uart`, `adc`)
3. Після цього перевіряти протокольні драйвери

## XC8
1. Відкрити проєкт у MPLAB X з XC8
2. Перевірити include paths і цільовий MCU
3. Поетапно зібрати `XC8/examples/*_example.c`

## Типові Проблеми
- Неправильний MCU header
- Неправильне значення частоти осцилятора
- Невідповідні config bits
- Відмінності синтаксису interrupt
