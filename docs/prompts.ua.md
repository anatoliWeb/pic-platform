# Набір промптів

Папка `prompts/` містить готові контекстні промпти для AI-чатів і локальних
LLM-інструментів.

## Призначення

Використовуйте ці промпти на початку нового чату про проєкти на базі
`pic-platform`. Вони передають асистенту правила платформи, архітектуру,
модель інтеграції з MPLAB та обмеження компіляторів.

## Доступні промпти

- [Контекст для ChatGPT](../prompts/chatgpt-platform-context.md)
- [Контекст для Ollama](../prompts/ollama-platform-context.md)
- [README папки prompts](../prompts/README.ua.md)

## Рекомендоване використання

1. Вставте потрібний промпт на початку чату.
2. Після нього додайте конкретний запит по проєкту.
3. Проєктну логіку залишайте в application layer.

## Нотатки

- Prompt для ChatGPT детальніший.
- Prompt для Ollama коротший і краще підходить для невеликих локальних моделей.
- У майбутньому можна додати промпти для code review, MPLAB integration або вибору модулів.
