# Набір промптів

Ця папка містить готові промпти для використання `pic-platform` в AI-чатах і
локальних LLM-інструментах.

Використовуйте ці файли на початку нового чату, коли потрібно, щоб асистент
допомагав з проєктами на базі цієї платформи.

## Файли

- [chatgpt-platform-context.md](chatgpt-platform-context.md) - основний промпт для роботи в чаті
- [ollama-platform-context.md](ollama-platform-context.md) - компактний промпт для локальних моделей Ollama

## Як користуватися

1. Відкрийте потрібний prompt-файл.
2. Вставте його на початку нового чату.
3. Додайте після нього запит для конкретного проєкту.

## Нотатки

- Промпти описують архітектуру репозиторію та правила використання.
- Платформа лишається зовнішньою щодо MPLAB-проєкту.
- Драйвери та бібліотеки не копіюються у папку застосунку.
- Використовуйте відносні шляхи та додавайте потрібні `.c` файли в MPLAB.
