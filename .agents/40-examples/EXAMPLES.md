# Examples

## Where examples live

- XC8 example projects live under `examples-projects/xc8/`.
- C18 example projects live under `examples-projects/c18/`.
- Shared support notes live in `examples-projects/README.md` and `examples-projects/README.ua.md`.
- Proteus notes live in `examples-projects/proteus/`.
- Reusable HEX artifacts live in `examples-projects/hex/`.

## Project structure

Typical MPLAB wrapper project contents:

- `main.c`
- `config_bits.c`
- `project_config.h`
- `nbproject/`
- build output folders generated by MPLAB

## What an example should show

- how to wire a reusable platform component into a project;
- which `.c` files are required;
- how `project_config.h` and `config_bits.c` are split;
- how the board is wired in Proteus;
- how the expected behavior looks at runtime.

## Do not hide important logic

- Example code should demonstrate orchestration, not bury reusable logic that belongs in `libraries/`.
- If the example contains logic that other projects need, move that logic into the platform.

## Regenerating HEX

- Regenerate HEX when the example source, config, or platform dependency changes.
- Refresh tracked HEX artifacts only after the build output is verified.

## Example families in this repo

- Root validation examples: `blink.X`, `gpio.X`, `adc_read.X`, `timer.X`, and other standalone smoke tests directly under `xc8/`.
- `debug/` family: `default_uart.X`, `display_i2c.X`, `display_parallel.X`, `pins_gpio.X`, `multi_backend.X`, `disabled.X`.

- `sensors/ds18b20/` family: `basic.X`, `read.X`, `multi_read.X`, `search_rom.X`.
- `input/` family: `button.X`, `encoder.X`, `adc_buttons.X`.
- `seven_segment` family: `basic_manual.X`, `multiplex_manual.X`, `multiplex_timer.X`, `keys_single_line.X`, `keys_diode_coded.X`.
- `output/` family: `software_pwm.X`, `ac_phase_control.X`.
- `timers/` family: `tick.X`, `timer0.X`..`timer3.X`.
- `system/wdt.X`.
- `actuator/position_drive_adc.X`.
