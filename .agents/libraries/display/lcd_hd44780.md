# lcd_hd44780

## Purpose

HD44780 character LCD driver with a GPIO 4-bit interface (`lcd_*`)
and a PCF8574 I2C backpack transport (`lcd_i2c_*`).

## Location

```text
 libraries/display/lcd_hd44780/lcd.h
libraries/display/lcd_hd44780/lcd_hd44780.h
libraries/display/lcd_hd44780/lcd.c
libraries/display/lcd_hd44780/lcd_i2c.h
libraries/display/lcd_hd44780/lcd_i2c.c
XC8/libraries/display/lcd_hd44780/lcd.c
C18/libraries/display/lcd_hd44780/lcd.c
```

## Use when

- you need reusable LCD character display support;
- you need an HD44780 behind a PCF8574 I2C backpack (`lcd_i2c_*`).

## Do not use when

- another display family is required.

## Error/status model

The I2C transport reports per-operation status through `lcd_i2c_last_status()`
and `lcd_i2c_is_ready()`:

- `LCD_I2C_OK` - last operation succeeded.
- `LCD_I2C_INVALID_ARGUMENT` - address `0x00` or above `0x7F`, cursor row > 1,
  or a backlight argument other than 0/1.
- `LCD_I2C_NOT_INITIALIZED` - operation before `lcd_i2c_init`/`attach`/
  `controller_init`, or a display operation while the ready flag is cleared.
- `LCD_I2C_NO_ACK` - the backpack did not ACK; the ready flag is cleared and
  the current operation short-circuits (no further I2C transactions). The
  failure reason stays visible through `lcd_i2c_last_status()`.

Display operations (`clear`, `home`, cursor, text, backlight) refuse to touch
the bus until the controller is initialized again through `lcd_i2c_init()` or
`lcd_i2c_controller_init()`. `lcd_i2c_write_string()` stops on the first failed
character write.

The 7-bit address is used as-is (no masking); address `0x00` and addresses
above `0x7F` are rejected at run time.

## Compile-time defines

The PCF8574 pin mapping is configurable. Defaults match the common backpack
layout P0=RS, P1=RW, P2=EN, P3=Backlight, P4..P7=D4..D7.

| Define | Default | Purpose |
| --- | ---: | --- |
| `LCD_I2C_PIN_RS` | `0x01u` | RS control pin mask |
| `LCD_I2C_PIN_RW` | `0x02u` | RW control pin mask |
| `LCD_I2C_PIN_EN` | `0x04u` | EN control pin mask |
| `LCD_I2C_PIN_BL` | `0x08u` | Backlight pin mask |
| `LCD_I2C_DATA_SHIFT` | `4u` | First data nibble bit position |

Invalid mappings (zero or multi-bit masks, overlapping masks, data pins
overlapping control pins, shift out of range) fail the build with `#error` in
`lcd_i2c.c`.

## Runtime model

LCD operations are synchronous controller writes. The I2C transport is
master-owned by this module only after `lcd_i2c_init`; `lcd_i2c_attach` binds
to a bus initialized elsewhere (probe only) and `lcd_i2c_controller_init()`
initializes the controller on the bound address.

## Resource ownership

LCD pins are project-owned.

## Integration recipe

1. Add the shared LCD source or selected compiler-specific source.
2. GPIO transport: bind pins, then initialize the controller.
3. I2C transport: add `lcd_i2c.c`, `i2c.c` and `core/delay.c`; call `lcd_i2c_init()`
   for a free bus, or `lcd_i2c_attach()` followed by `lcd_i2c_controller_init()`
   when the I2C master is already initialized elsewhere.
4. Write characters or strings; check `lcd_i2c_last_status()` for NACK.
5. After a runtime NACK, require an explicit re-init before writing again.

## Minimal usable example

```c
if (lcd_i2c_init(0x27u, 100000u) != LCD_I2C_OK) {
    /* backpack missing or miswired */
}
lcd_i2c_clear();
lcd_i2c_write_string("OK");
```
