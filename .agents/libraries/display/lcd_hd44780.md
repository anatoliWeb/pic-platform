# lcd_hd44780

## Purpose

HD44780 character LCD driver.

## Location

```text
libraries/display/lcd_hd44780/lcd.h
libraries/display/lcd_hd44780/lcd_hd44780.h
libraries/display/lcd_hd44780/lcd.c

XC8/libraries/display/lcd_hd44780/lcd_hd44780.c
C18/libraries/display/lcd_hd44780/lcd_hd44780.c
```

## Use when

- you need reusable LCD character display support.

## Do not use when

- another display family is required.

## Public API

| Function/type/macro | Exact signature/type | Purpose | Arguments | Returns/output | Side effects | Notes |
| --- | --- | --- | --- | --- | --- | --- |
| `lcd_init_pins` | `void lcd_init_pins(...);` | bind pins | hardware pins | none | configures pins | exact args in header |
| `lcd_init` | `void lcd_init(void);` | initialize LCD | none | none | initializes controller |  |
| `lcd_clear` | `void lcd_clear(void);` | clear LCD | none | none | sends clear command |  |
| `lcd_set_cursor` | `void lcd_set_cursor(uint8_t row, uint8_t col);` | set cursor | row, col | none | sends cursor command |  |
| `lcd_write_char` | `void lcd_write_char(char c);` | write char | character | none | writes data |  |
| `lcd_write_string` | `void lcd_write_string(const char* str);` | write string | string | none | writes data |  |
