# ili9341

## Purpose

ILI9341 TFT display driver.

## Location

```text
libraries/display/ili9341/ili9341.h
libraries/display/ili9341/ili9341.c
```

## Use when

- you need reusable ILI9341 display control.

## Do not use when

- a different display controller is required.
