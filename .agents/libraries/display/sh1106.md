# sh1106

## Purpose

SH1106 OLED display driver.

## Location

```text
libraries/display/sh1106/sh1106.h
libraries/display/sh1106/sh1106.c
```

## Use when

- you need reusable SH1106 display control.

## Do not use when

- a different OLED controller is required.
