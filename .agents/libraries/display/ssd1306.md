# ssd1306

## Purpose

SSD1306 OLED display driver.

## Location

```text
libraries/display/ssd1306/ssd1306.h
libraries/display/ssd1306/ssd1306.c
```

## Use when

- you need reusable SSD1306 display control.

## Do not use when

- a different OLED controller is required.
