# ws2812

## Purpose

WS2812 LED strip driver.

## Location

```text
libraries/led/ws2812/ws2812.h
libraries/led/ws2812/ws2812.c
```

## Use when

- you need reusable WS2812 strip control.

## Do not use when

- a different LED protocol is required.

## Public API

| Function/type/macro | Exact signature/type | Purpose | Arguments | Returns/output | Side effects | Notes |
| --- | --- | --- | --- | --- | --- | --- |
| `ws2812_color_t` | struct | RGB color | r/g/b | state | none |  |
| `ws2812_t` | struct | strip state | runtime state | state | none |  |
| `ws2812_init` | `uint8_t ws2812_init(...);` | initialize strip | config | success flag | configures hardware | exact args in header |
| `ws2812_set_pixel` | `void ws2812_set_pixel(...);` | set pixel | strip, index, color | none | updates buffer | exact args in header |
| `ws2812_set_all` | `void ws2812_set_all(...);` | set all pixels | strip, color | none | updates buffer | exact args in header |
| `ws2812_clear` | `void ws2812_clear(...);` | clear strip | strip | none | updates buffer | exact args in header |
| `ws2812_set_brightness` | `void ws2812_set_brightness(...);` | set brightness | strip, brightness | none | updates scaling | exact args in header |
| `ws2812_show` | `void ws2812_show(...);` | transmit data | strip | none | sends frame | exact args in header |

## Runtime model

Pixels are buffered and flushed with `ws2812_show()`.

## ISR requirements

Not applicable for this module.

## Resource ownership

WS2812 data pin is project-owned.

## Integration recipe

1. Add the shared WS2812 source.
2. Configure the strip.
3. Set pixels.
4. Flush with `ws2812_show()`.

## Minimal usable example

```c
ws2812_t strip;
ws2812_init(&strip, &cfg);
ws2812_show(&strip);
```

## Validation status

## Known limitations

Timing is protocol-sensitive.

## Common mistakes

- Compiling wrapper and shared source together.
