# apa102

## Purpose

APA102 LED strip driver.

## Location

```text
libraries/led/apa102/apa102.h
libraries/led/apa102/apa102.c
```

## Use when

- you need reusable APA102 strip control.

## Do not use when

- a different LED protocol is required.

## Public API

| Function/type/macro | Exact signature/type | Purpose | Arguments | Returns/output | Side effects | Notes |
| --- | --- | --- | --- | --- | --- | --- |
| `apa102_pixel_t` | struct | pixel color | RGB state | state | none |  |
| `apa102_t` | struct | strip state | runtime state | state | none |  |
| `apa102_init` | `uint8_t apa102_init(...);` | initialize strip | config | success flag | configures hardware | exact args in header |
| `apa102_set_pixel` | `void apa102_set_pixel(...);` | set pixel | strip, index, color | none | buffer update | exact args in header |
| `apa102_set_all` | `void apa102_set_all(...);` | set all pixels | strip, color | none | buffer update | exact args in header |
| `apa102_clear` | `void apa102_clear(...);` | clear strip | strip | none | buffer update | exact args in header |
| `apa102_show` | `void apa102_show(...);` | transmit frame | strip | none | sends frame | exact args in header |
| `apa102_set_brightness` | `void apa102_set_brightness(...);` | set brightness | strip, value | none | updates brightness | exact args in header |

## Configuration structures

Public fields are the `apa102_t` members described in the header.

## Runtime model

Pixels are buffered and flushed with `apa102_show()`.

## ISR requirements

Not applicable for this module.

## Resource ownership

APA102 data/clock pins are project-owned.

## Integration recipe

1. Add the shared APA102 source.
2. Configure the strip.
3. Set pixels.
4. Flush with `apa102_show()`.

## Minimal usable example

```c
apa102_t strip;
apa102_init(&strip, &cfg);
apa102_show(&strip);
```

## Validation status

Implemented in source; validation evidence not tracked in `.agents/`.

## Known limitations

Timing is protocol-sensitive.

## Common mistakes

- Writing without flushing.
- Treating it as a generic SPI wrapper.
