# ds1302

## Purpose

DS1302 RTC driver.

## Location

```text
libraries/time/ds1302/ds1302.h
libraries/time/ds1302/ds1302.c
```

## Use when

- you need reusable DS1302 RTC control.

## Do not use when

- another RTC chip is used.
