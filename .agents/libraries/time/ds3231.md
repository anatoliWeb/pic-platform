# ds3231

## Purpose

DS3231 RTC driver.

## Location

```text
libraries/time/ds3231/ds3231.h
libraries/time/ds3231/ds3231.c
```

## Use when

- you need reusable DS3231 RTC control.

## Do not use when

- another RTC chip is used.
