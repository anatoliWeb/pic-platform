# ds1307

## Purpose

DS1307 RTC driver.

## Location

```text
libraries/time/ds1307/ds1307.h
libraries/time/ds1307/ds1307.c
```

## Use when

- you need reusable DS1307 RTC control.

## Do not use when

- another RTC chip is used.
