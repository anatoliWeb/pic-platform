# Global Rules

- MUST check `git status` first.
- MUST protect dirty files that were already present.
- MUST search existing platform functionality before creating new code.
- MUST keep reusable code in `pic-platform`.
- MUST keep project-specific logic in projects.
- MUST update docs when behavior changes.
- MUST run targeted checks only by default.
- MUST NOT push unless asked.
- MUST NOT use `git add .`.
- MUST NOT duplicate libraries in projects.
- MUST NOT rewrite timer libraries without explicit need.
- MUST NOT change public API casually.
- MUST NOT invent unsupported compiler or MCU support.
- MUST NOT describe planned features as implemented.
