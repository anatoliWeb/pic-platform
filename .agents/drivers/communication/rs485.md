# rs485

## Purpose

## Runtime model

- Direction control is switched around blocking frame transfers.
- `rs485_send_frame()` blocks until all bytes are shifted out. All compiler paths (XC8, C18, shared fallback) use `rs485_wait_tx_complete()` which polls `TXSTAbits.TRMT` to guarantee the final byte has physically left the TX pin before switching direction.
- `rs485_receive_frame()` blocks with timeout while waiting for each byte.
- Direction switching includes guard delays for MAX487 transceiver settling.
- After `rs485_send_frame()`, the transceiver is automatically returned to RX mode.
- On timeout or CRC error, the caller should call `rs485_set_rx()` before the next receive attempt.

3. Switch TX/RX mode around transfers.
4. Use frame helpers when applicable.
