# C18

## Purpose

C18 compiler compatibility map.

## Location

```text
C18/
examples-projects/c18/
```

## Wrapper style

- Use `C18/drivers/...` and `C18/libraries/...` for C18-specific implementation details.

## Known limitations

- C18 compatibility relies on `core/compiler.h` typedefs and wrappers.

## Do

- Keep C18-only code in C18 paths.

## Don't

- Assume XC8 headers or syntax are available.
